# Project BloodLine

Website for [Project BloodLine™](https://andre-aguirre.github.io/project-bloodline/), a San Antonio 501(c)(3) nonprofit that teaches free, hands-on STOP THE BLEED® bleeding control classes in English and Spanish.

**Live site:** https://andre-aguirre.github.io/project-bloodline/

**Request a free training:** projectbloodlinesatx@gmail.com

## Pages

Every page has an English and a Spanish version.

| Page | English | Spanish |
|---|---|---|
| Home | `index.html` | `es/index.html` |
| About us | `about.html` | `es/nosotros.html` |
| Training | `training.html` | `es/capacitacion.html` |
| Impact | `impact.html` | `es/impacto.html` |
| Resources | `resources.html` | `es/recursos.html` |
| Questions | `questions.html` | `es/preguntas.html` |

`404.html` handles broken links in both languages. `sitemap.xml` lists every page for search engines.

```
website/
├── index.html, about.html, training.html, impact.html, resources.html, questions.html
├── es/            Spanish versions
├── assets/
│   ├── css/site.css
│   ├── js/site.js
│   ├── fonts/     Archivo variable font + license
│   └── img/       logos, photos, icons, social preview image
├── 404.html
├── sitemap.xml
└── .nojekyll
```
